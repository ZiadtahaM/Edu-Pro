# Security Policy

## Supported source branch

Security fixes target the current default branch. Repository collaborators must not expose student data, credentials, session tokens, database URLs, or private environment configuration in source control or issue threads.

## Reporting a vulnerability

Contact the repository owner privately with the affected area, reproducible steps, impact, and any remediation advice. Avoid public proof-of-concept publication until the issue is assessed and fixed.

## Education-data safeguards

Protect authorization decisions at the server boundary, validate user input, and apply migrations deliberately. Review automated dependency update pull requests and run the full type, test, and build workflow before release.
